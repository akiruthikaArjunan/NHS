Step 2:
First dependency — Selenium
Selenium is the tool that controls the browser — clicks buttons, types text, reads the page
Second dependency — WebDriverManager
This tool automatically downloads ChromeDriver for you. Without it, you'd have to manually download and set up ChromeDriver every time Chrome updates. WebDriverManager does it for you.
Third dependency — Cucumber Java
This is what lets us write tests in plain English. It reads your .feature files and understands the Given/When/Then steps.
Fourth dependency — Cucumber JUnit Platform Engine
This connects Cucumber to JUnit so your tests can actually run inside IntelliJ and Maven.
Fifth dependency — JUnit Platform Suite
This is what allows us to run the Cucumber tests as a test suite — basically the engine that powers the test runner.
